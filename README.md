# End-to-End E-Commerce Customer Churn Analysis & Retention Strategy

## 📌 Project Overview
This project analyzes 100,000+ customer transaction records to identify key drivers behind customer churn and build an actionable retention strategy.

## 🛠️ Tech Stack
* **Language:** Python (Pandas, NumPy, Matplotlib, Seaborn)
* **Database:** SQL (MySQL)
* **Visualization:** Power BI

## 📊 Key Highlights & Results
* Segmented customers using **RFM Analysis** (Recency, Frequency, Monetary).
* Built an interactive Power BI dashboard tracking CLV, Churn Rate, and MAU.
* Identified retention triggers predicted to reduce churn by **12%**.
